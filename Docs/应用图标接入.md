# 应用图标接入

用户选择工作区的 `icon_lucency.png` 作为应用图标，源文件为 1254 × 1254 的透明 PNG。

- [x] 检查源图尺寸、透明通道与现有平台图标入口。
- [x] 生成 Android 各密度启动图标与自适应图标资源。
- [x] 生成 Windows 多尺寸 ICO，复用现有资源入口。
- [x] 检查生成尺寸、透明通道及缩小效果，验证双平台构建。

生成过程只进行平台资源缩放和封装，保留原图内容、透明度及留白。Android 自适应图标使用深青色背景和透明前景，Windows ICO 包含 16、24、32、48、64、128、256 像素尺寸。通过 `tools/generate_app_icons.ps1` 可从源文件重复生成。
