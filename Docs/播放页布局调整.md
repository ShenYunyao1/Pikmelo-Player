## 验证记录

2026-11-13 完成共享播放页调整，Windows 与 Android 使用相同布局。底部控制区独立于上方滚动内容，SafeArea 避开系统手势区域，按钮上方依次为码率和进度条。码率与整个进度条组件左边缘对齐。封面尺寸系数由 0.42 调整为 0.378，最大尺寸由 340 调整为 306。

标题、作者与专辑各保留一行高度，超长时首部停顿 1 秒，按每秒 28 逻辑像素循环滚动，副本之间留 32 逻辑像素间隔。切歌按曲目标识重新开始，进度刷新保持滚动位置。缺失作者与专辑留空并保留行高。系统启用减少动画时使用单行省略，辅助功能语义提供完整文字。

音量入口位于播放方式左侧，浮层显示百分比及上增下减的竖向滑动条，点击外部关闭，复用共享控制器与已有持久化。完整播放页的播放按钮尺寸和按钮间距适配 320 逻辑像素窄屏，底部播放栏原有布局继续使用原参数。

新增四项组件回归，覆盖底部安全区和唯一队列入口、码率位置、三行长文字、进度变化不重置滚动、切歌回到起点、竖向音量拖动、浮层关闭、320×640 / 640×360 / 1280×800 和 1.8 倍字体。旧有载入取消提示的位置稳定性回归继续通过。音量 UI 测试控制器放在组件测试时钟中创建和清理，避免跨时钟异步队列阻塞清理。全量 147 项测试通过，静态分析无问题。

上方滚动区域与进度条之间额外固定保留 24 逻辑像素间距，滚动到中间位置时也不会贴近控制区。元数据中的换行符统一作为空格显示，保证全部文本可在同一行滚动。

最终 Windows release 与 Android armeabi-v7a、arm64-v8a、x86_64 三架构 release 构建通过。最新源码全量 147 项测试、静态分析与差异空白检查通过。此次保留当前开发版本号，仅本地提交，手机实机触控、实际字体及厂商手势区域显示待复核。
