## 实现与回归记录

2026-11-13 设置首页改为四个一级入口，二级页由独立组件提供，界面返回和 Android 系统返回均回到设置首页。服务器地址和 API Key 文本控制器仍由曲库页面持有，返回设置列表后保留草稿，原有连接成功返回曲库流程保持可用。下载管理、目录迁移恢复、曲目移动网络策略、缓存上限、队列恢复和应用音量已迁入对应二级页面。

单选弹层复用 RadioGroup，支持选择当前项后关闭，选项和页面支持滚动。设置列表、各二级内容使用独立组件身份，切换时避免沿用其他页面的滚动状态。搜索清除同步清空输入与筛选关键字，保留全部／已下载选择并显式回到输入焦点。

默认播放模式单独保存在 playback_preferences.default_mode，新建队列及向空队列追加曲目时应用。播放页切换模式继续作用于当前队列，快照新增 mode 字段保存该队列模式。旧偏好使用既有 mode 初始化默认值，旧快照仍可恢复，已有队列中的模式不会被修改默认值影响。

更新策略独立保存在 mobile_update_policy，新安装默认仅 Wi-Fi。对于旧配置，存在明确允许曲目移动下载的存储值时初始化为允许移动网络更新，其余情况采用仅 Wi-Fi，此后两项设置独立变化。版本查询可手动执行，安装包下载遵循更新策略，切换到受限网络或收紧更新策略会取消未完成下载。已校验的缓存 APK 可继续安装。Windows 保留打开 Releases 获取更新包的流程。

关于页保留当前版本、自动更新和完整下载、校验、授权与安装状态，增加项目仓库入口。仓库通过双平台现有原生桥接打开固定公开仓库地址，Android 浏览器启动异常返回界面提示。下载、更新和媒体迁移任务仍由页面外控制器管理。

设置一级导航回归先在旧实现中失败，实施后与新搜索回归均通过。完整 158 项测试和静态分析通过，覆盖搜索清除及焦点、输入草稿、系统返回、项目仓库调用、三种屏幕尺寸和 1.6 倍字体、默认模式迁移及恢复、两个独立网络策略、网络与策略变化时取消更新、更新卡片单选与状态入口。
