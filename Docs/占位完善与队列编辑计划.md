## Q2 验证记录

2026-11-13 完成跨进程恢复与播放设置，本轮继续仅本地提交。

- 新增共享 PlaybackSession，复用 app_settings 存储。队列快照按服务器与凭据指纹隔离，只保存曲目 ID、选中索引、进度和时长。模式和应用音量作为全局偏好保存，未配置服务器时也可调整。
- 启动默认启用队列恢复，恢复后保持暂停，不打开音源或触发音频下载。设置页提供恢复开关、四种播放模式和应用音量。关闭恢复会清理当前快照，模式及音量继续保存。
- 恢复时重新读取当前授权元数据与有效媒体路径，避免使用迁移前路径。失效曲目从队列中排除，原选中项失效时选择剩余首曲并将进度归零。未下载但有下载元数据的曲目保留在队列，等待用户播放时准备。
- 进度约每 2 秒保存一次，队列编辑、模式、音量、播放及停止状态变化立即保存，正常退出前刷新快照。异常写入不会打断播放，损坏的快照或偏好不阻断曲库启动。
- 任务移除改为停止和释放音源，保留队列快照，以支持下次启动恢复。显式清空队列会更新为空快照。正常退出在清理播放器前保存状态。
- 新增 7 项回归，完整 128 项测试通过，静态分析无问题。覆盖真实数据库重开、媒体路径重查、凭据隔离、无凭据时偏好保存、关闭恢复、清空快照、损坏偏好、授权撤销、正常连接恢复与设置页交互。
- Windows release 与 Android 三架构 release 构建通过，本地构建继续使用 1.0.5+105。真实手机的杀进程、系统回收、文档目录授权恢复及后台通知重播仍需实机复核。

专辑、时长等曲目信息继续按 Q3 实施，歌词界面保留后续阶段。

## Q3 验证记录

2026-11-13 完成普通元数据本地解析与展示，本轮继续仅本地提交，开发版本保持 1.0.5+105。

- 按用户确认，已下载曲目的普通元数据直接从音频读取。字段缺失时显示未知，不新增服务器补查。未下载曲目展示已有同步信息。封面及后续歌词继续采用内嵌优先、服务器回退。
