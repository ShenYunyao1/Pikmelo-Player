# 自定义存储与按需播放

用户于 2026-11-12 确认以下范围。Windows 与 Android 共用下载和播放准备逻辑。

## 已确认的交互

- 音频目录支持自定义，更换时可选择迁移已有文件或仅用于后续下载。
- 迁移先完成复制和校验，再更新记录并清理旧文件。
- 已下载曲目直接播放，未下载曲目下载完成后自动播放，播放期间准备下一首。
- 手动下载长期保留，播放下载与预下载使用有容量上限的缓存。
- 移动网络提供允许下载、仅播放前下载、禁止下载三个选项。

## 完成标准

旧版本下载保持可读取，自定义目录和策略重启后生效。未下载的授权曲目可从曲库、搜索、歌单及系统队列进入播放准备。快速切歌后仅最新选择可自动播放。移动网络禁止策略阻止手动下载、播放下载与预下载，同时允许播放已有文件。

Android 目录使用系统文档树 URI，文件存取与播放通过 URI 适配。跨存储迁移需要保留失败恢复信息，自动缓存回收仅处理播放缓存。


## 实现说明

- `MediaStorageController` 管理媒体目录、迁移日志、缓存容量与网络策略，`MediaFiles` 统一访问本地路径及 Android 文档 URI。
- Windows 使用系统文件夹选择器。Android 使用系统文档树选择器并持久保存读写授权，支持本地存储及设备支持的可移动存储。Android 的系统限制可能禁止选择存储根目录、Download 根目录或 Android/data。
- 原数据库与已有绝对路径继续使用。已有音频按长期下载导入保留策略，更换目录时逐首复制，核对大小及 SHA-256，更新数据库后清理旧文件。日志保留已复制位置，重启后可继续迁移。
- 仅用于后续下载时，旧文件保留原位置。未完成任务继续使用原半文件续传，完成后发布到新目录。Android 文档目录下载使用应用私有目录暂存完整音频，再复制校验到目标目录，暂存期间需要额外空间。
- 下载优先级依次为当前选择、手动下载和下一首预下载，当前选择可暂停后台任务并在之后恢复。顺序、列表循环和随机播放均使用实际下一首候选，单曲循环复用当前文件。
- 播放缓存采用最近使用时间清理，手动下载可永久保留，下载页可将缓存转为永久保留。当前曲目和下一首受保护，大文件可能暂时超过上限，切歌后继续回收。
- 本轮实现默认缓存上限为 1 GB，移动网络默认仅允许播放前下载。这两项属于可修改的实现默认值。设置页提供 256 MB、1 GB、4 GB 缓存选项及三种移动网络策略。
- 禁止下载同时阻止手动、播放前和预下载。已有文件可离线播放。Android 网络回调和 Windows 网络查询会暂停不符合当前策略的活动传输，暂停任务可手动继续。Wi-Fi 热点按操作系统报告的网络类型处理。
- 全屏播放页可取消播放准备，选择其他曲目及系统停止会取消旧等待，已手动保留的后台任务继续执行。
