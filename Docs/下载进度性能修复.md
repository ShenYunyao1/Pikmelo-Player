## 根因与修复

下载进度每约 200 ms 通知连接控制器，触发离线元数据扫描、缓存清理与全局页面刷新。普通元数据查询还会反复构造整库曲目列表。现在仅在已完成下载集合发生变化时处理曲库更新，下载页直接监听下载管理器的任务变化。曲目查找改为按 ID 读取。

歌单封面方法的 async 包装每次返回新 Future，FutureBuilder 重新进入等待状态时显示占位。现在按凭据范围、授权、封面标识和本地回退来源复用请求，复用覆盖同步和页面重建，成功封面可跨网络变化复用，失败保留一分钟重试窗口并允许网络变化后重试。

锁屏恢复原本每次调用连接同步。同步协议使用保存的游标，当前已提供可配置自动同步间隔。手动刷新立即执行。详细行为见[日志与同步设置](日志与同步设置.md)。
