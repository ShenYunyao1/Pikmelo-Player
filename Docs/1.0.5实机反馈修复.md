## 本地验证记录

- 本地版本为 1.0.5+105。通知停止及应用停止保留当前曲目、队列、进度，释放音源。再次播放重新打开音源、定位后播放。取消播放准备也保留队列，任务移除继续清理队列并释放音频焦点。
- Android 系统媒体项发布本地缓存文件 URI，复用内嵌优先的封面读取。曲目变化立即清除旧 URI，异步结果核对当前曲目及请求版本。通知图片解码限制 512 × 512，临时封面缓存上限 64 MiB。
- 曲目右侧两个操作槽各为 48 × 48，已下载图标和下载按钮保持相同中心坐标。正在播放页取消按钮隐藏时保留尺寸，移除点击与读屏响应。
- 新增五项回归，全量 121 项测试通过，静态分析无问题。验证停止后继续原进度、停止期间取消异步准备、迟到封面丢弃、下载前后对齐，以及加载前后进度和按钮坐标一致。
- Windows release 构建及可执行文件版本 1.0.5+105 已验证。Android 三架构 release 构建通过，ARM64 APK 的版本号 105 及正式证书指纹通过 aapt / apksigner 验证。
- 当前未连接 Android 设备。下拉通知及锁屏的实际封面显示、厂商系统停止和重播、实际触控与快速连续切歌需实机复核。Windows SMTC 封面不在本次 Android 通知修复验收范围内。
