# 日志与同步设置

## 同步间隔

- [x] 服务器配置新增同步间隔，默认 30 分钟，可选 20、10、5 分钟并保存。
- [x] 前台定时同步与恢复前台共用间隔，后台停止计时，手动刷新立即执行。
- [x] 覆盖默认值、持久化、定时触发、锁屏恢复与手动刷新测试。

## 日志

- [x] 新增共享 AppLog，异步批量写入，4 个各 5 MB 文件轮转，总容量最多 20 MB。
- [x] 新增“日志”一级设置，位于“关于”前，关于始终末尾。
- [x] 级别选择 error、warn、info、debug 并保存，默认 info。选择级别同时包含更严重级别。
- [x] 日志页显示占用、目录、最近记录，支持刷新、复制最近记录和清空。
- [x] 覆盖生命周期、导航、同步、下载、播放、设置、文件读写、歌词封面与网络请求日志。
- [x] 凭据脱敏，记录请求方法、无查询参数地址、状态、耗时和错误类别。
- [x] 回归容量轮转、并发写入、重启、级别、脱敏和日志 UI，全量 210 项测试与静态分析通过。
- [x] Windows 与 Android 三架构正式构建及 APK 固定签名核验。

主要文件为 lib/shared/app_log.dart、lib/settings/ui/log_settings.dart、lib/settings/connection_controller.dart、lib/settings/ui/connection_card.dart，以及各模块已有操作入口。日志写入使用有界队列和 1 秒批量刷新，下载字节和播放位置变化避免逐事件落盘或触发全局界面通知。超出队列容量时舍弃最早排队记录并记录计数。

自动同步遇到进行中的下载或媒体目录操作时每分钟重试，避免重建下载管理器中断当前下载。手动刷新仍沿用用户主动同步流程。日志级别采用最低严重程度筛选，debug 包含所有四级。日志目录为应用支持目录下的 PikmeloPlayer/logs，与媒体自定义目录独立。

## 验证结果

2026-11-15 完成 210 项自动测试和静态分析。新增回归覆盖默认同步间隔、保存与恢复、前后台生命周期、定时请求、手动刷新和下载中延后同步。日志回归覆盖四级筛选、嵌套凭据与 URL 脱敏、轮转容量、并发刷新、超长记录、有界队列、重启读取、清空，以及本地 HTTP 服务真实请求的 200 / 404 状态日志。设置页面在手机横竖屏、桌面和大字体场景通过布局检查。

日志页按最新优先显示最多 200 条记录，复制时按时间正序输出。默认 info 为本次实现选择。选择 debug 时会启用原有读写、歌词和帧统计诊断并写入循环文件，控制台输出仍由构建开关 PIKMELO_DIAGNOSTICS 控制。

- [ ] Android 实机检查日志页、持续 debug 记录和批量下载的实际帧率。

Windows 正式构建与原生按需播放、预下载、离线重开、迁移回归通过。Android 三架构 APK 通过既定正式证书 SHA-256 校验。Android 首次构建遇到镜像 Maven 元数据 424，使用同一项目与本机已有依赖执行 Gradle 离线正式构建成功。
