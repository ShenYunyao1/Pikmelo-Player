# 功能缺口与占位清单

记录日期为 2026-11-12，覆盖 Windows 与 Android 当前实现。用户要求先记录当前占位内容及尚未实现的功能，后续按实际开发结果维护复选清单。

当前版本处于核心流程可用的开发测试阶段，P6 整体验收仍在待办中。扩展功能的优先级、具体交互和实施阶段等待后续确认。

## 占位内容与界面完善

- [ ] 接入真实封面。目前歌单、曲目、播放页和队列统一使用名称首字与渐变色块，接入前需要确认服务器封面字段、接口及鉴权方式。
- [ ] 完善设置页的播放行为配置。目前“播放行为”仅展示固定行为说明，具体可配置项和默认值需在实施时确认。
- [ ] 完善曲目信息展示。目前列表主要显示标题、歌手和下载状态，设计稿中的专辑、列表时长及更多操作尚未完整落地，需结合实际元数据与交互范围细分。
- [ ] 更新按需播放相关文案。目前空播放器仍提示“选择一首已下载的曲目”，需要核对空状态、播放状态与队列文案，使其符合未下载曲目也可进入播放准备的行为。

## 播放队列与状态恢复

- [ ] 支持调整队列中曲目的顺序。
- [ ] 支持单独移除队列中的曲目。
- [ ] 支持向当前队列追加曲目。
- [ ] 重启后恢复上次播放队列。
- [ ] 重启后恢复上次播放位置，自动开始播放的规则待确认。
- [ ] 持久保存并恢复循环或随机播放模式。
- [ ] 持久保存并恢复应用内音量。

当前队列已支持查看和点击切歌，顺序、列表循环、单曲循环及随机播放已实现。上述条目补充队列编辑和跨进程恢复能力。

以下功能已记录为未实现项，具体范围与排期等待后续确认。

- [ ] 歌词展示。
- [ ] 收藏。
- [ ] 播放历史。
- [ ] 专辑独立浏览。
- [ ] 歌手独立浏览。

## 已实现功能的待验收事项

- [ ] 在 Android 实机验证来电、蓝牙、有线耳机、长时间锁屏省电及实际听感。
- [ ] 在 Android 实机验证触控、TalkBack 读屏、SD 卡目录访问及拔插恢复。
- [ ] 完成 release 构建的完整播放及系统媒体控制验收。
- [ ] 完成旧版本覆盖升级与数据保留验收。
- [ ] 配置正式发布签名及分发方式。当前 Android APK 沿用工程测试签名。

同步、下载续传、离线及按需播放、下一首预下载、目录迁移、缓存管理和系统媒体控制均已有业务实现。测试结果及验收范围见[整体开发计划](整体开发计划.md)与[自定义存储与按需播放计划](自定义存储与按需播放计划.md)。
