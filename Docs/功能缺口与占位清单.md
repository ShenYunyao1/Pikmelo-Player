# 功能缺口与占位清单

记录日期为 2026-11-12，覆盖 Windows 与 Android 当前实现。用户要求先记录当前占位内容及尚未实现的功能，后续按实际开发结果维护复选清单。

当前版本处于核心流程可用的开发测试阶段，P6 整体验收仍在待办中。扩展功能的优先级、具体交互和实施阶段等待后续确认。

## 占位内容与界面完善

- [x] Android 系统媒体通知封面已在本地 1.0.5 接入，异步串图回归通过，实机复核待办。
- [ ] Windows SMTC 封面接入。
- [x] 接入应用内真实封面。优先解析已下载曲目的内嵌图片，缺失时请求受鉴权的服务器封面，失败保留名称色块。详见[真实封面与内嵌资源计划](真实封面与内嵌资源计划.md)。
- [x] 完善播放设置。已提供启动恢复开关、播放模式和应用音量，默认暂停恢复。
- [x] 完善曲目信息展示。已下载音频直接解析普通元数据，补齐专辑、曲目时长、歌单已知总时长及曲目信息入口；缺失字段显示未知，未下载曲目使用已有同步信息。138 项测试与双平台正式构建通过，实机验收继续待办。
- [x] 更新按需播放相关文案。空播放器说明未下载曲目会先下载，空队列错误提示检查曲库授权与下载信息。

## 播放队列与状态恢复

- [x] 支持调整队列中曲目的顺序。支持拖动和菜单上移、下移。
- [x] 支持单独移除队列中的曲目。移除当前项切换可用项并保留暂停状态。
- [x] 支持向当前队列追加曲目。歌单曲目行提供加入队列入口，空队列追加后保持暂停。
- [x] 重启后恢复上次播放队列，按服务器和凭据隔离，排除失效曲目。
- [x] 重启后恢复上次播放位置，默认保持暂停，媒体路径重新校验。
- [x] 持久保存并恢复循环或随机播放模式。
- [x] 持久保存并恢复应用内音量。

当前队列已支持查看和点击切歌，顺序、列表循环、单曲循环及随机播放已实现。上述条目补充队列编辑和跨进程恢复能力。
